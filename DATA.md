# DATA.md

Публикуемые датасеты лежат в `public/data/` и доступны по адресам вида
`https://<owner>.github.io/representation-psychology/data/<file>.json`.

## Файлы

| Файл | Содержимое |
| --- | --- |
| `works.json` | Произведения корпуса: id, название, формат, годы, страны, жанры, описание |
| `scenes.json` | Единицы анализа (строка таблицы кодирования → одна запись) |
| `codebook.json` | Закрытый словарь категорий: значение, определение, пример |
| `meta.json` | Версия датасета, дата сборки, лицензия |
| `validation-report.json` | Отчёт валидатора: проверки, ошибки, предупреждения |

Схемы — в `data/schemas/`.

## Единица анализа

Одна строка таблицы кодирования = одна запись в `scenes.json`.

- `analysis_unit: "scene"` — запись с таймкодом (обычно один фрагмент фильма или серии).
- `analysis_unit: "work_overall"` — запись описывает произведение целиком («анализ сериала в целом» или пустой таймкод).
- Id единицы: `{work_id}-unit`. Если у произведения появятся отдельные сцены, добавятся `-s2`, `-s3`.

## Поля scenes.json

| Поле | Тип | Правило |
| --- | --- | --- |
| `id`, `work_id` | string | стабильные ключи, не пересчитываются при правке названий |
| `analysis_unit` | enum | `scene` / `work_overall` |
| `timecode` | string | как в источнике, пробелы нормализованы |
| `description` | string | `scene_description` |
| `space_type` | string \| null | код из словаря или `null` |
| `therapist_archetype` | string[] | коды из словаря |
| `ethical_violation` | `yes`/`partial`/`no`/null | машинный код; подписи — в codebook |
| `stigma_level` | `high`/`medium`/`low`/null | машинный код |
| `utterance_types`, `visual_tropes` | string[] | коды из словаря |
| `scene_function` | string[] | свободный текст, разделитель `;` — не из закрытого словаря |
| `note` | string | примечания и дословные цитаты снятых токенов |

## Правила кодирования

- Словарь заморожен. Токен, которого нет в `codebook.yml`, не становится кодом: он снимается с поля и целиком попадает в `note` с именем поля.
- Мультизначения в ячейке распознаются только если фрагмент совпадает с подписью словаря; «неразрывный дефис» и типографские кавычки приводятся к обычным.
- Пустые строки источника (например, «Даг») в JSON не попадают.
- Имена кодеров в публичные файлы не входят: столбец удалён из `data/source/coding.xlsx`, поля `coder` нет.
- `the_use_of_DH_tools` и пометки StoryMapJS/Voyant/Sutori не публикуются; текст сохраняется в `data/out/withheld.json` (не в git).

## Обновление данных

```bash
# заменить data/source/coding.xlsx, при необходимости codebook.yml и works.yml
npm run data    # → public/data/*.json + validation-report.json
npm run build   # → dist/
```

`npm run build` запускает ETL и падает, если валидатор вернул ошибки (D-07).

## Что валидатор считает ошибкой

- повторяющиеся id (works, scenes, codebook);
- `work_id` без произведения; пустые `analysis_unit`/`description`/`timecode`;
- код, которого нет в словаре; мультиполя не-массивы;
- пустая строка источника в JSON;
- имена кодеров в публичных JSON или в `data/source/coding.xlsx`;
- меньше семи глав или глава с менее чем двумя `scene_ids`, неизвестные `scene_id`;
- содержательная глава без `viz`.

Предупреждения сборку не останавливают и пишутся в `validation-report.json`: исключённые пустые строки, «в целом» у фильма, несколько таймкодов в ячейке, токены вне словаря.

## Цитирование

Название проекта, год, версия датасета (`meta.json → version`), URL страницы на GitHub Pages. Имен авторов и DOI в MVP нет.
